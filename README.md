## Selected Projects

### Lending Club Risk Scoring
Repository: [Joon-hub/LendingClubProject](https://github.com/Joon-hub/LendingClubProject)

A scalable PySpark pipeline that ingests, cleans, and evaluates millions of loan records to produce risk grades.

- Automated ingestion of multi-gigabyte datasets from HDFS and AWS S3.
- Custom risk-scoring algorithm utilizing Spark MLlib for performance optimization.
- Parameterized modules enabling flexible configuration for data sources and transformation rules.

### German Real-Estate Market Analysis
Repository: [Joon-hub/German-Real-state-Market-Analysis](https://github.com/Joon-hub/German-Real-state-Market-Analysis)

An integrated data pipeline and dashboard for German property listings spanning 2018 to 2020.

- Batch processing of CSV and JSON inputs with Spark and Python.
- Scheduled data ingestion and transformation orchestrated via Airflow DAGs.
- Interactive web dashboard developed with Dash and Plotly; price forecasting model built with XGBoost.

### Flight Fare Prediction
Repository: [Joon-hub/Flight_Fare_Prediction](https://github.com/Joon-hub/Flight_Fare_Prediction)

A comprehensive pipeline for forecasting airline ticket prices based on historical and real-time data.

- Extraction of temporal and route-based features from raw booking data.
- Modular preprocessing and training scripts structured for reproducibility.
- Model validation using k-fold cross-validation and error analysis to ensure robust performance.
